### Public repositories

**Nexus family: Claude, Codex and Antigravity at work on your PC, Chrome and phone**

| Repository | What it does | Stack |
| :--- | :--- | :--- |
| [**NexusSystem**](https://github.com/pironjulien/NexusSystem) | Installs and keeps up to date, in one click, the Nexus tools that give your AIs the use of your PC, phone and Chrome in the background. No account, no ads, no telemetry. On the [Microsoft Store](https://apps.microsoft.com/detail/9NSH2P3QLWT1). [Page](https://julienpiron.fr/nexussystem/) | `C#` `Windows` `Microsoft Store` |
| [**NexusWindows**](https://github.com/pironjulien/NexusWindows) | Windows computer use in the background for Claude, Codex and Antigravity: one native engine, three profiles, your desktop apps driven without taking your mouse, keyboard or focus, every action read back. [Page](https://julienpiron.fr/nexuswindows/) | `C#` `MCP` `Win32/UIA` |
| [**NexusBrowser**](https://github.com/pironjulien/NexusBrowser) | The user's real Chrome driven by AI agents (Antigravity, Claude, Codex) in background tabs, through a local authenticated bridge and one MCP server. [Page](https://julienpiron.fr/nexusbrowser/) | `JavaScript` `Chrome CDP` `C#` |
| [**NexusAndroid**](https://github.com/pironjulien/NexusAndroid) | Android computer use over plain ADB: one MCP server shared by Claude Code, Codex and Antigravity; no root, no app on the phone. [Page](https://julienpiron.fr/nexusandroid/) | `C#` `MCP` `ADB` |
| [**NexusKeypad**](https://github.com/pironjulien/NexusKeypad) | Claude, Codex and Antigravity as animated pixel-art characters on the Logitech MX Creative Keypad: agent states, quota gauges, one press to the conversation that needs you. [Page](https://julienpiron.fr/nexuskeypad/) | `C# .NET 10` `Logi Plugin` |
| [**NexusRelay**](https://github.com/pironjulien/NexusRelay) | Shared room for Claude, Codex and Antigravity on one Windows PC: each agent woken in its own desktop app, through one local MCP daemon. Experimental. [Page](https://julienpiron.fr/nexusrelay/) | `C#` `MCP` `PowerShell` |
| [**NexusAGYmail**](https://github.com/pironjulien/NexusAGYmail) | Gmail for Google Antigravity over the official Gmail API: sends only after your yes, no permanent deletion. [Page](https://julienpiron.fr/nexusagymail/) | `C#` `MCP` `Gmail API` |
