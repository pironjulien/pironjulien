# Security policy

Please report suspected vulnerabilities privately, never in a public issue:

- for a project, through the private vulnerability reporting of its repository
  (**Security** tab, then **Report a vulnerability**);
- for this profile repository, through
  [its private vulnerability reporting](https://github.com/pironjulien/pironjulien/security/advisories/new).

Include the affected repository, file or URL, the impact and the steps to reproduce.

## Disclosure

You will get a first answer within 3 days. A confirmed vulnerability is fixed in a new release, usually within 30
days, then disclosed in a GitHub security advisory that credits the reporter unless they prefer otherwise. Please
keep it private until the fix is out.
